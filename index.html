1 · Privacy & camera permission

No analytics

Camera access is off until you give consent and press Start camera. No microphone is requested.

Processed in your browserThe app's own code does not upload camera frames, face landmarks, activity scores, or self-checks to an app server.
Model files come from a CDNAfter you start, pinned MediaPipe scripts and model/WASM assets are downloaded from jsDelivr. The CDN may receive connection metadata.
No background data storeSession history and self-checks remain in page memory. There is no localStorage, cookie-based session, analytics tag, or automatic telemetry upload in this file.
You stay in controlStop camera to end capture. Export is manual and creates a CSV file only after you click the export button.

Start is disabled until the consent box is checked. For stricter network privacy, self-host audited, version-pinned model files instead of using a CDN.

What this privacy statement does — and does not — promise
  • This file contains no code that sends the computed data to an application backend.
  • The browser still downloads the third-party MediaPipe libraries and model assets from jsDelivr when camera processing starts. CDN requests can expose typical connection metadata such as IP address and request details.
  • Because a third-party library executes in the page, this is not equivalent to a fully offline or independently audited installation. This page does not claim that all network activity is eliminated.
  • For production use, review and self-host pinned dependencies, serve over HTTPS, and configure security headers at the hosting layer.

What this version can and cannot tell you

  • Can estimate: changes in gaze proxy and head pose relative to your personal baseline, when those signals are visible.
  • Cannot know: whether you understand the material, are thinking deeply while looking away, or are truly concentrating.
  • Not used as penalties: missing face data, brief eye closures, and missing hand data. The app reports unavailable input instead.
  • Not scientifically validated: the weights and tolerances are transparent engineering heuristics, not trained parameters backed by a controlled accuracy study.
